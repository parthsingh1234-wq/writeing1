# 📚 Article Vault

**Article Vault** is a full-stack content management and publishing application inspired by **Medium**, **Notion**, and **Google Docs**. Built with React, Vite, Node.js, Express, MongoDB Atlas, Cloudinary, and TipTap.

---

## ✨ Key Features

- **🔐 Authentication & Security:** JWT authentication, bcrypt password hashing, role-based authorization (User / Admin), password reset flows, profile management, Helmet HTTP headers, CORS, NoSQL injection protection, and rate-limiting.
- **✍️ TipTap Rich Text Editor:** Headings, Bold, Italic, Underline, Strikethrough, Bullet Lists, Numbered Lists, Blockquotes, Code Blocks, Tables, Hyperlinks, Text Colors, Highlights, Text Alignment, Word Count, Character Count, and Reading Time.
- **⏱️ 5-Second Auto-Save:** Background autosave engine with visual status indicators (`Saving...`, `Saved ✓`, `Offline Save`).
- **📜 Version Control & Timeline:** Snapshot creation on manual saves or publish events with a timeline UI for previewing and 1-click version restoration.
- **🖼️ Image Asset Library & Cloud Storage:** Drag-and-drop & paste image uploads with Cloudinary cloud storage integration (and local disk storage fallback). Image library manager page with search, copy image URL, and unused image deletion.
- **📰 Medium-Style Reader Experience:** Reading progress bar, auto-generated Table of Contents (TOC), author badge, view count tracker, and multi-format exporters.
- **📤 Multi-Format Export:** Export any article directly to **Markdown (.md)**, **HTML (.html)**, **Word Document (.docx)**, and optimized **Print/PDF**.
- **🗑️ Recycle Bin (Soft Delete):** Soft-delete articles with a dedicated trash view for restoring or permanently purging articles.
- **📊 Modern Dashboard & Admin Analytics:** Stats widgets for Total Articles, Drafts, Published, and Images. Admin console for system-wide user account management and platform stats.
- **🌓 Dark Mode:** Theme switcher supporting Light, Dark, and System preferences with glassmorphic styling.
- **⚡ Offline Sync:** Queue unsaved drafts when internet connection drops and automatically reconcile with the backend upon reconnection.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS, TipTap Editor, Lucide React, Axios, Canvas Confetti, DOCX.js.
- **Backend:** Node.js, Express.js, Mongoose (MongoDB Atlas), Cloudinary SDK, JWT, bcryptjs, Multer, Helmet, Sanitize-HTML.
- **Database:** MongoDB Atlas (Cloud) with in-memory / local file-backed JSON database store fallback for zero-setup offline execution.

## 🚀 Quick Setup & Installation

### Prerequisites
- Node.js (v18+)
- npm or yarn

### 1. Backend Setup
```bash
cd server
npm install
npm run seed     # Populates default admin, users, categories, tags, and articles
npm start        # Launches API server at http://localhost:5000
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev      # Launches Vite dev server at http://localhost:5173
```

## 🔑 Environment Variables

### Backend (`server/.env`)
```env
PORT=5000
NODE_ENV=development

# MongoDB Atlas (Optional - Falls back to local file store if omitted)
MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/article_vault?retryWrites=true&w=majority

# JWT Security
JWT_SECRET=super_secret_article_vault_jwt_key_2026_dev_mode
JWT_EXPIRES_IN=7d

# Cloudinary Credentials (Optional - Falls back to local /uploads if omitted)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Rate Limiting
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX=500
```

## 🔗 Key API Endpoints

### Authentication
- `POST /api/v1/auth/register` - Register user
- `POST /api/v1/auth/login` - Login user & receive JWT
- `GET /api/v1/auth/me` - Fetch profile

### Articles
- `GET /api/v1/articles` - List articles (with search `q=`, category, tag, status, pagination)
- `POST /api/v1/articles` - Create new article
- `GET /api/v1/articles/:idOrSlug` - Get single article (increments view count)
- `PUT /api/v1/articles/:id` - Update / auto-save article
- `DELETE /api/v1/articles/:id` - Soft delete (Move to Recycle Bin)
- `PUT /api/v1/articles/:id/restore` - Restore from Recycle Bin
- `GET /api/v1/articles/:id/versions` - List version history
- `POST /api/v1/articles/:id/versions/:versionId/restore` - Restore past version

### Media & Assets
- `POST /api/v1/images/upload` - Upload image asset (Cloudinary / Local)
- `GET /api/v1/images` - User image library
- `DELETE /api/v1/images/:id` - Delete image
